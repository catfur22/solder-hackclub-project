# solder-hackclub-project
This is a sans themed pcb that im making. It has a cool silkscreen and custom shape to recreate the character sans from Undertale. It has a led for an eye and when a button is held it makes it flash on and off.

## BOM

1x 555 timer
1x 5mm led
2x CR2032 battery cell to hold 2 batteries
1x 10uF capacitor
1x 6mm push button
1x 4.7K resistor
2x 47K resistor
1x 470 Resistor
